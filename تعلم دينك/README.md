# زاد | تعلّم دينك

موقع عربي إسلامي مبسّط يساعد الزائر على التعلّم عن القرآن والحديث والعقيدة والفقه والسيرة والأخلاق، مع أدوات للاستماع إلى القرآن وحفظه.

## المزايا

- يتيح اختيار المرحلة الدراسية من أول ابتدائي حتى ثالث ثانوي لتبسيط الشرح حسب المستوى.
- اختيار المستوى والمجال الإسلامي وكتابة الموضوع أو السؤال.
- يركّز شرح الموضوعات المتاحة على القرآن والحديث والعقيدة والفقه والسيرة والأخلاق.
- قسم ظاهر للبحث عن السور الـ١١٤ بالاسم واختيارها من القائمة.
- عرض آيات أي مقطع تحدده بأرقام البداية والنهاية وتشغيل المقطع كاملًا تلقائيًا بصوت قارئ تختاره، مع تجهيز ملف الآية التالية مسبقًا لتقليل الفاصل، وخيار تكرار كل آية وإعادة المقطع وتمييز الكلمة المتلوّة عند توفر توقيتها.
- نموذج موضوع يعرض شرحًا ومثالًا وسؤالًا عند توفره.
- أمثلة وأسئلة مع تلميحات، وزر يوسّع الشرح تدريجيًا.
- حفظ الدروس والخطط في المتصفح، مع إمكانية فتحها مجددًا أو حذفها.
- تصميم عربي متجاوب بلا حساب أو خادم أو مكتبات إضافية. تحميل نص القرآن يحتاج الإنترنت.

## التشغيل

افتح `index.html` في متصفح حديث. يحتاج تحميل الآيات إلى اتصال بالإنترنت، ويعمل الموقع عبر GitHub Pages على HTTPS.

## النشر على GitHub Pages

1. أنشئ مستودع GitHub جديدًا.
2. ارفع الملفات الثلاثة الموجودة بجانب هذا الملف إلى جذر المستودع: `index.html` و`style.css` و`app.js`.
3. من إعدادات المستودع افتح **Pages**، واختر النشر من الفرع الرئيسي ومجلد الجذر.
4. بعد النشر سيعطيك GitHub رابطًا عامًا للموقع.

## ملاحظات

- ليست هذه فتوى أو مصدرًا معتمدًا للأحكام؛ ارجع إلى أهل العلم والمصادر الشرعية الموثوقة في المسائل التي تحتاج تحققًا.
- البحث عن السورة وعرض الآيات وتشغيلها لا يستخدمون الميكروفون. صوت التلاوة يُبث من EveryAyah عند التشغيل ويحتاج اتصالًا بالإنترنت. توقيت الكلمات يُحمّل من بيانات Quran Timings API عند توفرها للقارئ والسورة.
- نص الآيات يُحمّل عند الطلب من [AlQuran Cloud API](https://alquran.cloud/api). فهرس أسماء السور متاح أيضًا في [توثيق Quran Foundation](https://api-docs.quran.com/docs/content_apis_versioned/4.0.0/list-chapters/). راجع المصحف أو معلّمًا عند تصحيح التلاوة.
- لا توجد تفسيرات مضمونة لمعاني السور؛ ميزة السور هنا للمساعدة على الحفظ والتسميع فقط.
- الدروس تحفظ محليًا في المتصفح والجهاز الذي أضافها؛ لا تنتقل تلقائيًا إلى جهاز آخر.
- استخدم محتوى تعليميًا تملك حق مشاركته عند نشر المشروع.
