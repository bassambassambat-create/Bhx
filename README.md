 🧰 Toolbox

Toolbox is a free, all-in-one collection of browser-based tools designed to make everyday tasks easier, faster, and more convenient.

It brings together text utilities, calculators, converters, generators, productivity tools, prayer times, file transfer, and many other useful utilities in one simple interface.

Everything is designed to work directly in your web browser.

🇺🇸 English

📖 About

Toolbox is a browser-based collection of useful tools for everyday tasks.

Instead of opening many different websites for small jobs, Toolbox puts many utilities together in one application.

The project includes tools for text processing, encoding, calculations, conversions, productivity, time management, file transfer, prayer times, and more.

The application is designed to work locally in the browser whenever possible.

📱 PC ↔ Phone File Transfer

Toolbox includes a direct file-transfer tool designed to transfer files between devices.

The transfer system uses WebRTC peer-to-peer communication.

Instead of uploading a file to a traditional file-storage server, the devices establish a connection and transfer the file directly when the connection allows it.

The application uses a signaling process based on connection codes and WebRTC connectivity.

💾 Local Storage

Some features use browser local storage to save information locally.

For example:

* Notes
* To-Do items
* Prayer-time preferences

This allows certain information to remain available when the user returns to the application in the same browser.

⸻

🔒 Privacy

Toolbox is designed around browser-based processing.

The application’s description states that its tools operate locally in the browser.

For features that use browser storage, information can remain in the user’s own browser rather than being stored in a Toolbox account.

The file-transfer feature uses WebRTC for device-to-device communication rather than a traditional file-upload workflow.

⸻

🌐 No Account Required

Toolbox is designed as a browser application rather than an account-based service.

Users can open the application and use its tools directly without needing to create an account for the basic functionality.

⸻

📱 Mobile Friendly

Toolbox can also be used on smaller screens.

The interface switches to a mobile-friendly layout when the screen width becomes smaller, making the navigation and tools easier to use on phones and tablets. toolbox.html

🚀 How to Use

Using Toolbox is simple:

1. Open the Toolbox webpage.
2. Choose your preferred language.
3. Select a tool from the navigation menu.
4. Enter the required information.
5. Press the appropriate action button.
6. View the result.

No complicated installation process is required for normal browser use.

⸻

💻 Running Locally

You can also run Toolbox locally.

Open the project HTML file in a modern web browser.

The main project file is:

toolbox.html

For features such as WebRTC and browser APIs, using a modern browser is recommended.
